# Local LLM Humor Analysis Showcase

Sanitized public mirror of local LLM and NLP experimentation code. It keeps the
implementation history for retained Python modules while removing network setup
notes, tunnels, private configuration and operational artifacts.

## What This Demonstrates

- FastAPI-style Python service structure
- Local Ollama/Bielik experimentation
- Humor feature extraction and analyzer pipelines
- Image description and provider-selection modules
- Testable modular Python code with requirements and scripts

## Sanitization Notes

This repository is a portfolio extract, not a full deployment bundle. Private
networking, tunnel and key-management material was intentionally excluded.
